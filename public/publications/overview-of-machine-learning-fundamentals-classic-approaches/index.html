Overview of Machine Learning Part 1: Fundamentals and Classic Approaches

Farhad Maleki, Katie Ovens, Keyhan Najafian, Behzad Forghani, Caroline Reinhold, Reza Forghani

A review written for clinicians and imaging researchers, covering classic supervised and unsupervised machine learning, the full predictive modeling workflow, and the practices that decide whether a model generalizes. Written around the constraint that defines medical datasets: small sample sizes and missing values.

Abstract

As health data and computer power become increasingly available, the main challenge is to gain actionable insight from these data. Machine learning methods have proved to be a viable approach for mining valuable insight from data across various fields. This article provides an overview of the classic supervised and unsupervised machine learning methods as well as fundamental concepts required for understanding how to develop generalizable and high-performance machine learning applications. It also describes the important steps for developing a machine learning model and how decisions made in these steps affect model performance and ability to generalize. Key points: small sample sizes and missing values are two common characteristics of medical datasets that make developing predictive models challenging; classic machine learning methods can be used to build predictive models using small datasets; developing a machine learning application requires following a workflow including data acquisition, exploratory data analysis, data cleaning, dimensionality reduction, model building and validation, and model evaluation; understanding model complexity, variance, and bias is required for the successful application of machine learning; and following best practices for model evaluation is necessary for developing generalizable models.

Key contributions

  • Lays out the end-to-end predictive modeling workflow: data acquisition, exploratory analysis, cleaning, dimensionality reduction, training and validation, and evaluation.
  • Explains the bias-variance tradeoff and its relationship to model complexity in terms usable by clinical researchers.
  • Covers class imbalance, a defining feature of health data, and the tradeoffs of oversampling against undersampling.
  • Sets out evaluation practice: held-out test sets, nested cross-validation, and choosing performance measures that reflect the clinical question.

Methods and techniques

  • Linear and logistic regression
  • Support vector machines and the kernel trick
  • K-nearest neighbors
  • Naive Bayes
  • Decision trees and random forests
  • Multilayer perceptrons and backpropagation
  • Principal component analysis and t-SNE
  • K-means and hierarchical clustering
  • Feature selection: filter, wrapper, and embedded methods

Applications

  • Teaching machine learning method selection to radiologists and clinical researchers
  • Model development practice for small medical datasets
  • Reference for evaluation and validation design in clinical machine learning

Related work in Precision Health

Machine learning prediction of brain metastasis invasion pattern on brain magnetic resonance imaging scans

Neuro-Oncology Advances 2024

Brain metastasis invasion pattern is prognostic but can currently only be read from resected tissue. This study shows it can be predicted from preoperative MRI with 85% accuracy, using radiomic features from the peritumoral edema, in a task where expert neuroradiologists reach only 44 to 59%.

A Deep Learning-Based Pipeline for Celiac Disease Diagnosis Using Histopathological Images

CAIP 2021

Diagnoses celiac disease from whole slide images of duodenal biopsies using far fewer slides than a conventional pipeline needs. An Image Assembler synthesizes training examples by recomposing tissue segments onto a blank canvas, and patient-level predictions come from a majority vote across 101 synthesized images.

Using Deep Learning to Determine Kidney Function Decline in Patients with ADPKD

JASN 2023

Predicts which patients with autosomal dominant polycystic kidney disease will lose kidney function rapidly, by fusing MRI features with clinical variables rather than relying on height-adjusted total kidney volume alone.
